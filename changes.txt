PROJECT BLACK VEIN ORACLE — WHAT WE DID & WHAT'S LEFT

BACKEND — WHAT WE BUILT (after schema + db connection)
======================================================

1. SERVER SETUP
   - index.js: Express.js server on port 6001, CORS enabled, cookie-parser for JWT cookies
   - dbConnection.js: PostgreSQL connection pool to Supabase cloud database
   - serverConfig.js: Environment config (PORT, JWT_SECRET, DB_URL)
   - Location: Backend/src/index.js, Backend/src/config/

2. AUTHENTICATION SYSTEM (JWT + Cookies)
   - jwtToken.js: Generates JWT token and sets it as HTTP-only cookie (7-day expiry)
   - isAuthenticated.js: Middleware that reads JWT cookie, verifies token, sets req.id
   - Every entity (admin, thana, officer, jail, user) has signin + signout endpoints
   - Signin: validates email/password with bcrypt, returns JWT cookie
   - Signout: clears the JWT cookie from browser
   - Location: Backend/src/utils/jwtToken.js, Backend/src/utils/isAuthenticated.js

3. ROLE-BASED ACCESS CONTROL (RBAC)
   - requireRole.js: Middleware that checks user role from ID prefix (ADM, THN, OFC, JAL, USR)
   - 5 roles: admin (full access), thana (their data), officer (view+respond), jail (their jail), user (GD reports only)
   - Applied to every protected route — blocks unauthorized access with 403
   - Location: Backend/src/utils/requireRole.js

4. FOUR-LAYER ARCHITECTURE (for every entity)
   - Repository: Raw SQL queries to PostgreSQL (INSERT, SELECT, UPDATE, DELETE)
   - Service: Business logic layer calling repository functions
   - Controller: Handles HTTP request/response, error codes (409 duplicate, 400 bad FK, 500 server)
   - Router: Express routes with middleware chains (isAuthenticated → requireRole → controller)
   - Location: Backend/src/repositories/, services/, controllers/, routes/v1/

7. ERROR HANDLING (applied to all 19 controllers)
   - PostgreSQL error code 23505 → 409 "Record already exists" (duplicate)
   - PostgreSQL error code 23503 → 400 "Referenced record does not exist" (bad FK)
   - All other errors → 500 "Internal server error"

   - Location: Backend/src/routes/apiRouter.js, Backend/src/routes/v1/v1Router.js
